### HTTP Status Codes

HTTP status codes indicate the result of an HTTP request sent by a client to a server.

| Code | Meaning |
|---|---|
| `200` | OK Successful request |
| `301` | Permanent redirect |
| `302` | Temporary redirect |
| `400` | Bad request |
| `401` | Unauthorized |
| `403` | Forbidden |
| `404` | Not found |
| `500` | Internal server error |
| `502` | Bad gateway |
| `503` | Service unavailable |
| `504` | Gateway timeout |

**Important:** These status codes are useful when troubleshooting web servers, APIs, Nginx, and cloud applications.
